# Midad - Freelance Services Marketplace

Midad is a modern freelance services marketplace website, similar to Khamsat & Mostaql. A clean demo version, ready to customize for any client.

## Live Demo
[https://YOUR-USERNAME.github.io/midad-website/](https://github.com/MohayDevX)

## Features
- Modern & clean homepage
- Projects / Services section
- Fully responsive - works on mobile & desktop
- Easy to customize colors, texts & logo
- Fast & lightweight - HTML, CSS, JS only

## Technologies
- HTML5
- CSS3
- JavaScript

## How to use
1. Download / Clone this repo
2. Open index.html in your browser
3. Edit texts, colors and logo from index.html and styles.css

## Customization Available
Name, logo, colors, language (Arabic / English), sections and pages can be changed on request.
